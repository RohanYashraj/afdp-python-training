# Python Data Analysis Tutorial

Welcome to the Python Data Analysis Tutorial. This package is part of the Actuarial Faculty Development Program (AFDP) and contains materials for Python course.

## Contents

- `File1.ipynb`: Jupyter Notebook for the first lesson, covering Python basics.
- `File2.ipynb`: Jupyter Notebook for the second lesson, focusing on data analysis using NumPy, Pandas, and Matplotlib.
- `File3.ipynb`: Jupyter Notebook for the third lesson, covering intermediate Python concepts such as functions, file handling, and exception handling.
- `File4.ipynb`: Jupyter Notebook for the fourth lesson, focusing on advanced data manipulation and visualization using Pandas and Seaborn.
- `us_health_insurance_dataset_afdp.csv`: The dataset used in the notebooks.
- `README.md`: Instructions for using these materials.

## Requirements

- Either have the access to google colab. You can access it from https://colab.research.google.com/
- Or have Anaconda installed on your computer. You can download it from https://www.anaconda.com/products/individual.

## Dataset Source

The dataset used in these lessons was obtained from Kaggle: [US Health Insurance Dataset](https://www.kaggle.com/datasets/teertha/ushealthinsurancedataset?resource=download).

## Instructions for Use

1. **Launch Jupyter Notebook:**

   - Open Anaconda Navigator.
   - Launch Jupyter Notebook from the Anaconda Navigator.

2. **Navigate to the Project Directory:**

   - In the Jupyter Notebook interface, navigate to the directory where you have the files.

3. **Open the Notebooks:**

   - Click on `File1.ipynb` to start with the first lesson.
   - After completing the first lesson, proceed by opening `File2.ipynb` for the second lesson...

4. **Run the Notebooks:**

   - Follow the instructions in each notebook.
   - The dataset (`us_health_insurance_dataset_afdp.csv`) is already included in the same directory, so you don’t need to set up paths. The notebooks are configured to automatically find and use the dataset.

5. **Saving Your Work:**
   - As you work through the notebooks, remember to save your changes by clicking on the save icon or using the shortcut `Ctrl + S` (Cmd + S on Mac).

## Troubleshooting

If you encounter any issues:

- Ensure that the dataset file (`us_health_insurance_dataset_afdp.csv`) is in the same directory as the notebooks.
- If you encounter a path error, check that you have navigated to the correct directory in Jupyter Notebook.
- For any Python or library-related errors, ensure your Anaconda environment is set up correctly with the required libraries (`numpy`, `pandas`, `matplotlib`).

We hope you find these lessons helpful and enjoy learning Python!

Happy coding!
